# CI/CD Notes

## Continuous Integration (CI)
Automatically builds and tests code whenever changes are pushed.

## Continuous Deployment (CD)
Automatically delivers verified code.

## Pipeline Stages

### Build
Compiles or prepares the application.

### Test
Checks whether the application works correctly.

### Deploy
Releases the application (simulated in this project).

## Benefits
- Faster delivery
- Fewer errors
- Automated workflows
