# DecodeLabs Internship – DevOps Projects

## Project Title

DecodeLabs Internship – DevOps Learning Journey

## Description

This repository contains all the projects completed during my DecodeLabs DevOps Internship. It covers Linux fundamentals, Git & GitHub workflows, and CI/CD implementation using GitHub Actions.

### Projects Included

#### Week 1 – Linux Basics

* Linux commands and navigation
* File and directory operations
* Directory structure understanding

#### Week 2 – Git & GitHub

* Repository creation
* Commit management
* Git workflow
* GitHub integration

#### Week 3 – CI/CD Pipeline

* GitHub Actions
* Build → Test → Deploy workflow
* Automated pipeline execution

## How to Run

### Clone the Repository

```bash
git clone https://github.com/Vedantpatel2006/DecodeLabs-Internship.git
cd DecodeLabs-Internship
```

### View Week 1 Files

```bash
cd Week1-DevOps
```

### View Week 2 Files

```bash
cd Week2-CICD
```

### Trigger CI/CD Pipeline

Push any change to the `main` branch:

```bash
git add .
git commit -m "Trigger workflow"
git push
```

Then check the **Actions** tab on GitHub to view the pipeline execution.
